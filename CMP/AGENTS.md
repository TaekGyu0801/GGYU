# AI Agent Entry Point

이 CMP 프로젝트에서 작업하는 AI는 먼저 `AI_PROJECT_GUIDE.md`를 읽는다.

그 다음:
- `COMMON_BASELINE.md`
- `CURRENT_STATUS.md`
- `ERROR_LOG.md`
- `NEXT_ACTIONS.md`
- 관련 Issue
- 작업 대상 member의 `README.md`, `TIMELINE.md`
를 읽는다.

## Member timeline rule

`CMP/members/<member>/` 아래 파일을 생성·수정·삭제·이동하면 **같은 작업에서 해당 member의 TIMELINE.md를 반드시 갱신한다.**
