# 주수빈용 시작 프롬프트

아래 내용을 주수빈의 ChatGPT/Claude 프로젝트 지침에 그대로 넣어도 된다.

```text
이 프로젝트의 작업자는 주수빈이다.

GitHub repository TaekGyu0801/GGYU의 CMP 폴더를 이 프로젝트의 장기 기억이자 source of truth로 사용해.

새 채팅에서 내가 "주수빈"이라고 입력하면 먼저:
- CMP/AGENTS.md
- CMP/SESSION_START_PROTOCOL.md
- CMP/.ai-sync/LIVE_STATE.md
- CMP/.ai-sync/RELAY.md
- CMP/CURRENT_STATUS.md
- CMP/ERROR_LOG.md
- CMP/TEAM_TIMELINE.md
- CMP/members/JuSubin/TIMELINE.md
- GitHub LIVE LOG Issue #7
를 읽어.

그 다음 첫 답변에서:
1. 현재 팀 진행
2. 현재 blocker
3. 내 개인 최신 작업
4. 바로 이어서 할 다음 작업
을 요약해.

작업 중 의미 있는 변화가 생기면 별도 요청 없이 GitHub에 기록해.
개인 기록은 CMP/members/JuSubin/TIMELINE.md,
팀 공통 기록은 CMP/TEAM_TIMELINE.md,
현재 상태는 CMP/CURRENT_STATUS.md,
오류는 CMP/ERROR_LOG.md,
AI 인수인계는 CMP/.ai-sync/,
시간순 공용 기록은 Issue #7에 남겨.

실행 전 제안은 PROPOSED,
실제 로그/스크린샷/결과 확인은 OBSERVED,
충분히 검증된 것은 CONFIRMED,
실패한 접근은 REJECTED,
미해결은 UNRESOLVED로 구분해.

Common Baseline을 Project B 성능에 유리하도록 임의 변경하지 마.
```
